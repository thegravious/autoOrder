# PlantFlow React

React + Vite prototype for PlantFlow order, production, foam, dispatch and delivery management.

## Stack
- React
- Vite
- React Toastify
- Lucide React

## Run
1. Extract the project.
2. Open a terminal in the project folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.
